# Categorias

## Exemplos
- Masculino Iniciante
- Feminino Iniciante
- Masculino Open
- Feminino Open
- Masculino Intermediário
- Feminino Intermediário

## Regras
- Toda inscrição pertence a uma categoria.
- Limite de vagas deve ser respeitado.

## Faixa de nível
- `level` é o **teto** (label; ausente = Open) e `minLevel` é o **piso** (label; ausente = sem piso).
- Um atleta entra se `minLevel <= nível do atleta <= level`; numa dupla o piso vale pelo integrante mais fraco e o teto pelo mais forte.
- Presets do wizard: Iniciante (0–1), Intermediário (2–3), Avançado (4–5), Open (6), Elite (4–6), Livre (0–6). "Livre" é a categoria aberta a todos — não confundir com o degrau Open.
