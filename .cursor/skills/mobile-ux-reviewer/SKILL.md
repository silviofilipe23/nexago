## Checklist

### Clareza

- O usuário entende a tela?
- O objetivo está claro?

### Hierarquia

- Existe destaque visual correto?
- O CTA principal é óbvio?

### Complexidade

- Existem passos desnecessários?
- Existe excesso de informação?

### Conversão

- O fluxo incentiva a ação desejada?

### Mobile

- Botões possuem tamanho adequado?
- Componentes estão acessíveis?
