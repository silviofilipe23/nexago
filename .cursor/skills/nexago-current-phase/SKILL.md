# Fase Atual do NexaGO

O produto está em fase de crescimento inicial.

Prioridades:

1. Aumentar número de atletas cadastrados
2. Aumentar inscrições em torneios
3. Aumentar recorrência de uso
4. Consolidar o ranking
5. Criar comunidade

Sempre priorize funcionalidades que contribuam para esses objetivos.

Evite funcionalidades complexas que atendam poucos usuários.
