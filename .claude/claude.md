# Projeto

NexaGO é um ecossistema para gestão esportiva.

Objetivos:

- Escalabilidade
- Alta performance
- Excelente UX
- Arquitetura limpa
- Código de fácil manutenção

Stack

Flutter
Dart
Firebase
Firestore
Cloud Functions
FCM

Arquitetura

Feature First

Cada feature possui:

- presentation
- application
- domain
- infrastructure

Princípios

Nunca gerar código complexo sem necessidade.

Sempre priorizar:

- simplicidade
- legibilidade
- escalabilidade
- baixo acoplamento
- alta coesão

Nunca quebrar regras de negócio.

Sempre preservar retrocompatibilidade.
